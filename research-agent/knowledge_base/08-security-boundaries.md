# 研究 Agent 的安全边界
标题: 研究 Agent 的安全边界
来源: 本地演示知识库 / 公开资料整理

企业知识研究助手处理文档和模型输出时，需要把知识库内容视为不可信数据。文档中可能包含提示注入、越权指令或误导性内容，模型不应因为文档写了“忽略规则”就改变系统约束。检索结果应作为证据而不是控制指令，生成器提示词要明确区分系统规则、用户问题和文档内容。

权限过滤必须发生在检索之前，而不是生成之后。用户只能检索其有权访问的文档切片；缓存、任务元数据和记忆也必须按租户或用户隔离。演示项目不使用真实公司数据，但仍应保留数据分类、脱敏和清理接口，方便后续接入合规环境。

输出侧需要记录引用、模型版本、提示词版本和任务日志，以支持审计。对高风险结论可要求多来源支持或人工确认。重试和降级要有明确上限，避免系统在外部服务异常时无控消耗。
