# 企业知识库建设要点
标题: 企业知识库建设要点
来源: 本地演示知识库 / 公开资料整理

企业知识库不是简单地把文件放进向量数据库。文档解析要保留标题、章节、表格、页码和来源等结构信息；切片要避免把完整语义切断；索引要记录版本、权限和更新时间。对于扫描件、表格和复杂版式，可能需要 OCR 或结构化解析，但 MVP 可以先支持 Markdown、文本和 PDF。

知识治理决定 RAG 上限。重复文档、过期文档和相互冲突的内容会导致检索结果不稳定，因此需要去重、版本管理、失效标记和质量抽查。检索结果应同时返回相似度和来源信息，必要时增加重排模型或规则过滤，但不能用重排掩盖基础数据质量问题。

研究助手还应支持增量更新和重索引。每次重建后要保留一次快速质量检查，例如固定问题集上的 Recall@k 和 MRR，防止解析或模型升级导致指标回退。
