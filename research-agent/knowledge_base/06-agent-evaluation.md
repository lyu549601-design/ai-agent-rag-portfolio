# Agent 评估与质量闭环
标题: Agent 评估与质量闭环
来源: 本地演示知识库 / 公开资料整理

Agent 评估需要同时覆盖最终结果和过程行为。过程指标包括计划是否覆盖主题、依赖拓扑是否合法、同层并行是否生效、重试次数、失败任务和耗时；结果指标包括完成率、引用正确率、事实支持度、格式达标率和用户可追问性。

低成本方案采用分层评估。第一层是确定性校验，例如任务是否全部完成、章节是否齐全、引用标识是否真实、报告长度是否合理。第二层是 LLM-as-judge，对完整性、逻辑一致性和证据支持度打分。第三层是人工抽检，用来校准自动评估器和发现评分偏差。

记忆消融是研究 Agent 的重要实验。固定其他变量，只开启或关闭跨步骤记忆，对同一组主题重复运行。完成率的判定建议由校验器与 LLM Judge 共同给出，并保留原始报告和逐任务日志。结果报告应列出样本量、两次运行的条件、完成率变化、平均分数和失败案例，而不是只给一个提升百分比。
