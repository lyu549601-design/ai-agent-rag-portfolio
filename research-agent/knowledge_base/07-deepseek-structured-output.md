# DeepSeek 与结构化输出
标题: DeepSeek 与结构化输出
来源: 本地演示知识库 / 公开资料整理

DeepSeek 提供 OpenAI 兼容的聊天接口，常见用途包括任务规划、内容生成、结构化 JSON 输出和质量判断。为了避免供应商锁定，代码应通过一个薄封装统一模型名称、超时、温度、重试和 JSON 解析，而不是在每个 Agent 中直接创建客户端。

Planner 的输出需要经过程序校验，不能因为模型返回了 JSON 就信任。系统应检查任务数量、字段类型、唯一 id、依赖是否存在以及是否存在环。解析或校验失败时，必须使用确定性计划降级，保证 CLI 演示不会因为模型格式波动而完全中断。

执行阶段的温度通常低于创意写作，但低温度仍可能产生幻觉。提示词需要明确提供证据范围、引用格式和信息不足时的处理方式。Reviewer 可以使用更低温度和 JSON 输出，但自动评分不宜作为唯一事实标准，关键结论仍需要确定性校验或人工抽检。
