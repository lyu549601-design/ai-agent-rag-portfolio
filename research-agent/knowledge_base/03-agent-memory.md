# Agent 记忆的分层设计
标题: Agent 记忆的分层设计
来源: 本地演示知识库 / 公开资料整理

Agent 记忆通常可以分为工作记忆、情节记忆和长期知识。工作记忆服务当前步骤，只保留必要的任务说明与最近结果；情节记忆记录某个任务的跨步骤摘要、证据和反馈；长期知识则由 RAG 知识库或数据库提供。把三者混在一个无限增长的对话历史中，会带来成本、噪声和遗忘问题。

研究任务中，跨步骤摘要能够把上游结论压缩成可复用上下文，反馈缓存能够把 Reviewer 指出的问题带入重试，证据向量则允许后续步骤按语义找回先前用过的材料。记忆写入必须带任务标识和来源，读取时只检索当前任务或当前授权范围内的内容，避免不同用户之间串数据。

验证记忆是否有效，不能只看最终报告是否变长。更可信的方式是做消融实验：固定主题、模型、检索器、提示词和重试策略，只切换记忆开关，比较任务完成率、引用正确率、审核分数和耗时。样本需要覆盖多步骤依赖任务，并使用自动校验加人工抽检，避免把偶然波动包装成收益。
