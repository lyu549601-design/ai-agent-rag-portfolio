# 引用可信与证据回指
标题: 引用可信与证据回指
来源: 本地演示知识库 / 公开资料整理

研究助手的可信度取决于每个关键结论能否回到真实证据。生成时可以向模型提供带唯一标识的切片，例如 chunk_id、标题和来源，并要求只在句末引用真实标识。报告汇总阶段再根据标识生成来源列表，避免模型自行编造链接或页码。

校验不能只判断文本中“有方括号”。系统需要提取引用标识，与本次实际提供的证据集合比对；不存在的标识应判定为幻觉引用。还应对每个章节设置最低证据要求，并抽样检查答案是否被引用内容真正支持。引用存在并不等于引用正确，语义支持需要人工抽检或更强的判定模型。

为降低错误传播，RAG 结果应保留文档版本、切片位置和更新时间。知识库更新后要能够重建索引，并对旧报告标注证据版本。对于冲突证据，系统应展示冲突而不是把多个说法简单拼接成一个确定结论。
