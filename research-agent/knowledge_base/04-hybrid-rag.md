# 混合检索与 RAG 质量
标题: 混合检索与 RAG 质量
来源: 本地演示知识库 / 公开资料整理

RAG 的基本流程包括文档解析、切片、索引、查询、召回、重排和基于证据生成。关键词检索对专有名词、编号和精确术语敏感；向量检索更适合语义相近但字面不同的表达。单独使用一种方法容易出现漏召回或语义漂移，因此企业知识库常用混合检索。

混合检索可以先分别得到关键词排名和向量排名，再用 Reciprocal Rank Fusion（RRF）融合。RRF 只依赖名次而不依赖不同检索器不可比较的原始分数，适合快速建立稳定基线。对于中文文档，关键词侧需要分词或 n-gram 处理，向量侧需要统一维度和距离度量。

检索质量需要独立评估。Recall@k 衡量前 k 个结果覆盖了多少相关文档，MRR 衡量第一个相关结果出现得有多早。评估集必须包含问题与标准答案，并明确相关文档或切片。至少应对比纯关键词、纯向量和混合检索，报告指标与样本量，不能只展示几个成功案例。
