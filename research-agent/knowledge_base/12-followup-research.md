# 报告追问与可追溯问答
标题: 报告追问与可追溯问答
来源: 本地演示知识库 / 公开资料整理

研究任务结束后的追问不应重新从零开始。系统需要保存报告、子任务结论、引用和任务级摘要，再根据问题同时检索历史记忆与原始知识库。历史记忆提供上下文连续性，原始知识库提供可验证证据，两者缺一不可。

追问回答应沿用与主报告相同的引用规则：只引用本次返回或任务历史中真实存在的 chunk_id，不能沿用已经失效的旧引用。对于报告中未覆盖的问题，应明确说明知识库证据不足，而不是用模型常识补成事实。

当追问涉及报告中的结论时，可以返回对应的章节和来源；当追问提出新问题时，Answering Agent 可以执行一轮轻量检索，但仍需标注证据边界。保存历史问答有助于审计和优化，但必须按任务隔离并在清理时一并删除。
